## Installation

1. Download `build/vis_filets_generator_v1.9.0.rbz`
2. In SketchUp: **Window → Extension Manager → Install Extension**
3. Select the `.rbz` file → click **Install**
4. Restart SketchUp

For the boolean operations (Hex nut, Tap, Chamfer), you need either:
- **SketchUp Pro** (native Solid Tools), or
- **Eneroth Solid Tools** (free plugin, compatible with SketchUp Make)

## Thread type

| Option | Profile | Typical use |
|--------|---------|-------------|
| **ISO metric** | Standard 60° V-profile (ISO 261/724) | Metal parts, fasteners |
| **FDM plastic optimised** | V-profile, angle-limited + flat root | 3D-printed parts |

Switch between modes freely — each mode remembers its own parameters independently.

---

## Parts to create

Check one or more parts. All checked parts are generated simultaneously at the origin.

### Threaded rod

External thread, axis Z, base at origin.

| Field | Description |
|-------|-------------|
| **height** | Total length of the rod (mm) |

The top face is flat. Add a **Chamfer** (see Options) for a lead-in on the top end.

### Hex nut

Generated by boolean subtract (solid hex prism − threaded bore rod).

| Field | Description |
|-------|-------------|
| **height** | Axial height of the nut (mm) |

The bore diameter is `D + 2 × Gap`. Hex outer size follows DIN 934.

**FDM hint**: a warning `⚠ N×P` appears if nut height < 3 × pitch — too few thread turns for good grip. Target `✓` (≥ 3×P) for reliable printed nuts.

### Tap

A tap-shaped solid: threaded bore + relief cylinder + square drive, with a 45° entry cone at the bottom.

| Field | Description |
|-------|-------------|
| **height** | Length of the **threaded bore** section (mm). The full tap is taller due to the shank and square. |

The threaded length is automatically extended to compensate for the entry cone, so the effective thread engagement equals the value entered.

The tap is designed to be **subtracted from any solid** to create a threaded hole — see [Using the tap](#using-the-tap-as-a-subtraction-tool).

**Tap color**: if an object with a material is selected in SketchUp when you click Generate, the tap inherits that color. Useful for matching your SolidBatch subtract-color workflow.

---

## Dimensions

| Field | Description |
|-------|-------------|
| **M size** | ISO preset dropdown M3–M32. Select **Custom** for free input. |
| **D (mm)** | Nominal diameter. Auto-filled from M size, always editable. |
| **Pitch P (mm)** | Thread pitch. Auto-filled (ISO table or `0.25 × D` for FDM), always editable. |

> Engagement hint: the dialog shows the recommended engagement length (≥ 2×D, ideal 3–4×D).

---

## Options

| Field | Applies to | Description |
|-------|-----------|-------------|
| **Gap (mm)** | Hex nut, Tap | Radial clearance added to the bore. Default 0.3 mm (ISO) / 0.4 mm (FDM). Increase for looser fit, decrease for press-fit. |
| **Tap color** | Tap | Color swatch — click to pick from the selected SketchUp object. If the object has no material, the tap gets no color (SketchUp default). |
| **Thread lead-in chamfer** | Rod, Nut | Boolean subtract of a ring frustum. Tapers the thread crests over the chamfer height. |
| **Chamfer height (mm)** | Rod, Nut | Axial height of the chamfer zone. Default = 1 pitch. |
| **Max overhang angle (°)** | FDM only | Flank angle from vertical. Default 60° (= 30° from horizontal, standard printer). Higher = deeper thread. |
| **Min. core (%D)** | FDM only | Minimum core diameter as % of D. Prevents the thread root from going too deep. Default 70%. |
| **Segments / turn** | All | Angular resolution. Must be a multiple of 6. Default 24. Increase for smoother appearance (impacts performance). |

## Generating

1. Check the parts you want
2. Set dimensions and options
3. Click **Generate**

All parts are generated at the **origin** (0, 0, 0). Move and position them as needed after generation.

Each generated group is named (e.g. `Tap M10x1.5 L20 ISO`) and appears in the **Outliner**.

---

## Using the tap as a subtraction tool

The tap is a **single watertight solid** ready for boolean subtraction.

**Workflow:**

1. Generate the tap (check ☑ Tap, set height = desired thread depth)
2. Position the tap where you want the threaded hole — align the pointed tip on the entry face
3. Select the tap, then use **Solid Tools → Subtract** (Pro) or **Eneroth Solid Tools → Subtract**:
   - Target = the workpiece
   - Tool = the tap
4. The tap is consumed; the workpiece now has a threaded bore

**Tips:**
- The **pointed tip** makes it easy to center the tap on a circle or an axis intersection
- The **square drive** is a visual reference — it stays outside the workpiece
- Assign the tap a distinctive color (e.g. SolidBatch subtract color) so it's instantly recognizable in the model

---

## FDM printing tips

### Rod
- Gap 0.4 mm with FDM profile gives a smooth sliding fit
- Gap 0.3 mm gives a tighter fit (hand-tight assembly)
- Print upright (Z axis = thread axis) for best layer adhesion across thread flanks

### Nut
- Nut height ≥ 3×P for reliable grip (`✓` indicator in the dialog)
- FDM nut at 70% min core + 60° overhang angle prints cleanly on most printers without supports

### Chamfer
- Recommended for both rod and nut in FDM — the chamfer height = 1 pitch gives a clean lead-in and compensates for the first layer squish

## Pièces à créer

Cocher une ou plusieurs pièces. Toutes les pièces cochées sont générées simultanément à l'origine.

### Tige filetée

Filet externe, axe Z, base à l'origine.

| Champ | Description |
|-------|-------------|
| **height** | Longueur totale de la tige (mm) |

La face haute est plate. Ajouter un **Chanfrein** (voir Options) pour un guidage d'entrée.

### Écrou hexagonal

Généré par soustraction booléenne (prisme hex plein − bore rod fileté).

| Champ | Description |
|-------|-------------|
| **height** | Hauteur axiale de l'écrou (mm) |

Le diamètre de l'alésage est `D + 2 × Gap`. La taille hex suit la norme DIN 934.

**Indication FDM** : un avertissement `⚠ N×P` s'affiche si la hauteur < 3 × pas — trop peu de spires pour un bon maintien. Viser `✓` (≥ 3×P).

### Taraud (Tap)

Solide en forme de taraud : alésage fileté + cylindre de dégagement + carré d'entraînement, avec un cône d'entrée 45° en bas.

| Champ | Description |
|-------|-------------|
| **height** | Longueur de la **section filetée** (mm). Le taraud complet est plus haut (cylindre + carré). |

La longueur filetée est automatiquement allongée pour compenser le cône d'entrée — la longueur de taraudage effective correspond à la valeur saisie.

Le taraud est conçu pour être **soustrait de n'importe quel solide** afin de créer un trou fileté — voir [Utiliser le taraud](#utiliser-le-taraud-comme-outil-de-soustraction).

**Couleur du taraud** : si un objet avec un matériau est sélectionné dans SketchUp au moment du clic sur Générer, le taraud hérite de cette couleur. Pratique pour s'intégrer dans un workflow SolidBatch.

| Champ | Description |
|-------|-------------|
| **M size** | Dropdown ISO M3–M32. Choisir **Custom** pour saisie libre. |
| **D (mm)** | Diamètre nominal. Auto-rempli depuis M size, toujours éditable. |
| **Pitch P (mm)** | Pas du filet. Auto-rempli (table ISO ou `0,25 × D` en FDM), toujours éditable. |

> Indication d'engagement : le dialog affiche la longueur d'engagement recommandée (≥ 2×D, idéal 3–4×D).

## Options

| Champ | S'applique à | Description |
|-------|-------------|-------------|
| **Gap (mm)** | Écrou, Taraud | Jeu radial ajouté à l'alésage. Défaut 0,3 mm (ISO) / 0,4 mm (FDM). Augmenter pour un jeu glissant, diminuer pour un emmanchement serré. |
| **Tap color** | Taraud | Swatch de couleur — cliquer pour prendre la couleur de l'objet sélectionné dans SketchUp. Si l'objet n'a pas de matériau, la couleur SketchUp par défaut est utilisée. |
| **Thread lead-in chamfer** | Tige, Écrou | Soustraction booléenne d'un tronc de cône annulaire. Amortit les crêtes du filet sur la hauteur du chanfrein. |
| **Chamfer height (mm)** | Tige, Écrou | Hauteur axiale de la zone chanfreinée. Défaut = 1 pas. |
| **Max overhang angle (°)** | FDM uniquement | Angle des flancs depuis la verticale. Défaut 60° (= 30° depuis l'horizontale, imprimante standard). Plus élevé = filet plus profond. |
| **Min. core (%D)** | FDM uniquement | Diamètre noyau minimum en % de D. Empêche la racine du filet d'être trop profonde. Défaut 70%. |
| **Segments / tour** | Toutes | Résolution angulaire. Multiple de 6 obligatoire. Défaut 24. Augmenter pour un aspect plus lisse (impact sur les performances). |

## Générer

1. Cocher les pièces souhaitées
2. Régler les dimensions et options
3. Cliquer **Générer**

Toutes les pièces sont générées à l'**origine** (0, 0, 0). Les déplacer et positionner ensuite.

Chaque groupe généré est nommé (ex. `Tap M10x1.5 L20 ISO`) et apparaît dans le **Gestionnaire de calques/groupes**.

## Utiliser le taraud comme outil de soustraction

Le taraud est un **solide watertight unique** prêt pour la soustraction booléenne.

**Procédure :**

1. Générer le taraud (cocher ☑ Tap, hauteur = profondeur de taraudage souhaitée)
2. Positionner le taraud à l'emplacement du trou fileté — aligner la pointe sur la face d'entrée
3. Sélectionner le taraud, puis utiliser **Solid Tools → Subtract** (Pro) ou **Eneroth Solid Tools → Subtract** :
   - Cible = le volume à tarauder
   - Outil = le taraud
4. Le taraud est consommé ; le volume a maintenant un alésage fileté

**Astuces :**
- La **pointe conique** facilite le centrage sur un cercle ou une intersection d'axes
- Le **carré d'entraînement** est un repère visuel — il reste hors du volume à tarauder
- Assigner une couleur distinctive au taraud (ex. couleur de soustraction SolidBatch) pour le repérer facilement dans le modèle

---

## Conseils impression FDM

### Tige
- Gap 0,4 mm avec profil FDM = jeu glissant fluide
- Gap 0,3 mm = assemblage à la main plus serré
- Imprimer debout (axe Z = axe du filet) pour une meilleure résistance des flancs

### Écrou
- Hauteur ≥ 3×P pour un bon maintien (indicateur `✓` dans le dialog)
- Profil FDM à 70% min core + 60° overhang imprime proprement sur la plupart des imprimantes sans support

### Chanfrein
- Recommandé pour tige et écrou en FDM — hauteur = 1 pas, guide l'assemblage et compense l'écrasement de la première couche
